## 🎓 Cómo Personalizar Aún Más

Si quieres ajustar después:

### Cambiar Tono de Voz
Edita `brand-guidelines.json`:
```json
"tone_of_voice": {
  "personality": "Tu descripción aquí"
}
```

### Agregar Zonas de Cobertura
```json
"coverage_zones": [
  "Tu zona 1",
  "Tu zona 2"
]
```

### Cambiar Emojis Preferidos
```json
"emoji_palette": [
  "🐾", "❤️", "Tu emoji aquí"
]
```

### Ajustar Colores (SI ES NECESARIO)
```json
"colors": {
  "primary": { "hex": "#TU-COLOR" }
}
```
